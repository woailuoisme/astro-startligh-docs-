## 概览

MQTT5 用于设备侧长连接：自动售货机上报冰柜、货道、微波炉、门锁、控制板和网络状态；运营平台下发远程维护命令。订单创建、支付、出餐和加热任务由业务 HTTP 服务发起，MQTT5 只负责设备监控与维护通道。

## 集成边界

- MQTT5 承载设备监控与维护，不承载应用端订单状态同步。
- 应用端实时同步使用 [WebSocket](/websocket/)。
- 运营后台事件流使用 [SSE](/sse/)。
