## 业务事件

| 事件 | 频道 | 说明 |
| --- | --- | --- |
| `order.payment_authorized` | `private-order.{orderId}` | 支付已授权，可以创建出餐任务。 |
| `dispense.started` | `private-order.{orderId}` | 设备开始从冰柜货道出餐。 |
| `dispense.slot_unlocked` | `private-order.{orderId}` | 目标货道或取餐门已解锁。 |
| `heating.started` | `private-order.{orderId}` | 微波炉开始加热。 |
| `heating.completed` | `private-order.{orderId}` | 加热完成。 |
| `pickup.ready` | `private-order.{orderId}` | 盒饭可取。 |
| `order.completed` | `private-order.{orderId}` | 订单完成。 |
| `order.failed` | `private-order.{orderId}` | 订单失败，需要补偿或退款。 |
| `refund.pending` | `private-user.{userId}` | 退款已进入处理队列。 |
