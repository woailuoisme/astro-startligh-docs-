## 概览

WebSocket 用于应用端实时同步订单状态、支付状态、出餐流程、微波炉加热进度和取餐结果。协议采用 Pusher Channels 风格的消息信封、连接事件、订阅事件和私有频道鉴权方式，便于移动端复用成熟的事件模型。

命令类操作不通过 WebSocket 发起。创建订单、支付、出餐和加热任务必须调用业务 HTTP 服务，WebSocket 只负责把结果推送到应用端。
