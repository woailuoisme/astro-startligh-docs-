## 生产范围

<CardGrid>
	<Card title="冰柜盒饭" icon="open-book">
		库存以设备货道和盒饭 SKU 为核心，记录保质期、温控状态和可售数量。
	</Card>
	<Card title="微波加热" icon="setting">
		出餐和加热分开建模，支持加热任务、温度达标结果和失败补偿。
	</Card>
	<Card title="远程维护" icon="information">
		MQTT5 承载设备诊断、暂停售卖、门锁授权、固件升级和执行回执。
	</Card>
	<Card title="可审计" icon="approve-check-circle">
		支付、出餐、加热、维护和告警确认都保留可追踪的审计记录。
	</Card>
</CardGrid>
